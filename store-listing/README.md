# 上架资料清单

此目录包含：
- listing-zh.md：中文上架文案与合规说明
- privacy-policy.md：隐私政策文本（如需提供 URL，可用此内容发布到你的站点）
- promo-small.png：可选小型宣传图 440x280
- promo-marquee.png：可选大型宣传图 1400x560

仍需你提供：
- 实际功能截图 1-5 张（1280x800 或 640x400）
  - 建议截图主题：元素属性、间距测量、记录问题、粘贴设计参考图、HTML 反馈报告

可选：
- 如果你有品牌官网，可将 privacy-policy.md 发布并填入 URL

发布新版本前：
- 对照 `manifest.json` 逐项填写 `listing-zh.md` 中的权限理由，尤其是 `unlimitedStorage`。
- 确认商店后台的数据使用声明与 `privacy-policy.md` 一致。
