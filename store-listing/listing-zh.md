# 上架资料（中文）

## 基本信息
- 扩展名称：PixelAudit 视觉走查助手
- 简短描述（<=132字）：网页视觉走查与测距工具：查看元素尺寸、边距与距离，记录问题并导出本地 HTML 报告。
- 详细描述（建议 1-3 段）：
  视觉走查助手是一款用于网页 UI 验收与设计还原的效率工具。点击工具栏图标即可启动，悬停查看尺寸/字体/颜色，冻结后显示内外边距与父级间距，并支持两元素测距。

  适用于设计走查、前端对齐、复刻确认等场景。所有计算在本地完成；记录草稿仅保存在本地浏览器中，不会上传或共享。

## 单一目的说明
- 本扩展唯一目的：提供网页元素尺寸/间距/距离的可视化检查，并记录和导出走查结果。

## 权限说明
- activeTab：仅在用户点击扩展后，对当前标签页进行注入。
- scripting：向当前页注入检查脚本。
- storage：在本地浏览器中保存和恢复当前页面的走查草稿与修改记录。
- downloads：在用户主动导出时，下载本地 HTML 走查报告。

## 隐私说明（可作为隐私政策内容）
- 不收集、不上传、不共享任何用户数据。
- 用户创建的走查草稿和修改记录仅保存在本地浏览器中。
- 不与第三方服务通信。
- 所有功能均在本地浏览器环境中运行。
