# 上架资料（中文）

## 基本信息
- 扩展名称：PixelAudit 视觉走查助手
- 简短描述（<=132字）：网页视觉走查与测距工具：查看元素尺寸、边距与距离，记录问题并导出本地 HTML 报告。
- 详细描述（建议 1-3 段）：
  PixelAudit 是一款用于网页 UI 验收与设计还原的视觉走查工具。点击扩展图标即可启动，可查看元素尺寸、字体、颜色和间距，进行单元素或双元素测量，并记录元素或区域问题。

  记录问题时可粘贴设计参考截图；导出的 HTML 报告支持开发填写问题备注、粘贴反馈截图、标记完成状态并下载反馈版。所有内容均在本地处理和保存，不会上传到开发者服务器。

## 单一目的说明
- 本扩展唯一目的：提供网页元素尺寸/间距/距离的可视化检查，并记录和导出走查结果。

## 权限说明
- activeTab：仅在用户点击扩展后，对当前标签页进行注入。
- scripting：向当前页注入检查脚本。
- storage：查询本地存储用量，并迁移旧版本保存在 `chrome.storage.local` 中的走查草稿。
- unlimitedStorage：在用户本地保存视觉走查记录、页面截图、设计参考图和反馈图片，避免多张图片超过浏览器默认存储额度。数据不会上传、跟踪或与第三方共享。
- downloads：在用户主动导出时，下载本地 HTML 走查报告。

## 隐私说明（可作为隐私政策内容）
- 不收集、不上传、不共享任何用户数据。
- 用户创建的页面标题与 URL、走查草稿、截图、问题说明、反馈内容和修改记录仅保存在本地浏览器中。
- 不会自动向第三方传输走查数据；只有用户主动点击“问题反馈”或“小红书”时才会打开对应外部页面，扩展不会附带走查内容。
- 所有功能均在本地浏览器环境中运行。
